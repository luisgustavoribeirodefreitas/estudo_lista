# Laboratório APS — 3 listas + Reforço UML

Abra `index.html` no navegador. Funciona sem internet.

- 31 atividades originais adaptadas para resposta visual das três listas.
- Enunciado completo da lista aparece em cada atividade, com a fonte indicada.
- 4 atividades extras de `«include»`/`«extend»` baseadas nos slides `SEMANA05.pdf`, `casos-uso_2.0.pdf` e `documentos_casos_uso_2.0.pdf`.
- Nas oficinas UML A–C, arraste Casos de Uso, escolha tipo de relação, clique na origem e no destino. A correção verifica a presença dos casos, tipo e direção da seta, além de relações excedentes.
- Exercício UML D é de múltipla escolha.
- O gabarito é uma solução de referência didática, não gabarito oficial das listas.

Para publicar no GitHub Pages, deixe estes três arquivos na mesma pasta e configure a publicação dessa pasta ou da raiz do repositório.
